# The Legend of Zelda Movie — One-Page Fan Site

A standalone static HTML/CSS/JS one-page fan site for `zeldathemovie.com`.

## Files
- `index.html` — page content
- `styles.css` — responsive design
- `script.js` — release countdown + header effect
- `favicon.svg` — simple original favicon

No copyrighted Zelda artwork is bundled. The visual treatment uses original CSS/SVG shapes and gradients.

## Publish for free with GitHub Pages

1. Create a GitHub account if you do not already have one.
2. Create a **public** repository, e.g. `zelda-movie`.
3. Upload all files in this folder.
4. In GitHub: **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Wait for GitHub Pages to publish the site.
8. In **Settings → Pages → Custom domain**, enter:
   `zeldathemovie.com`
9. At one.com, remove the existing Figma `www` CNAME and configure the GitHub Pages DNS records shown by GitHub.

For an apex domain (`zeldathemovie.com`), GitHub Pages currently documents these A records:
- 185.199.108.153
- 185.199.109.153
- 185.199.110.153
- 185.199.111.153

For `www`, GitHub Pages uses a CNAME pointing to your GitHub Pages host, e.g. `YOURUSERNAME.github.io`.

GitHub may take some time to issue HTTPS after DNS is correct.
